# Agentic Workflow Automation

Agentic AI workflows for small businesses using n8n, integrating APIs (Gmail, Google Sheets, Hunter.io, Gemini, Claude) to automate multi-step processes like lead qualification, outreach, and data collection. (Ongoing)
